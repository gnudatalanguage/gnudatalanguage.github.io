### Or compile the code.
Two mains paths : 

 ## use the script `scripts/build_gdl.sh` 

 -  You need a [c++ compiler](https://github.com/gnudatalanguage/gdl/wiki/C----Compilers) , Cmake (version > 3.2), curl or wget, git
 -  You can _sudo_
 -  Download the gdl code (or [clone GDL](https://github.com/gnudatalanguage/gdl/wiki/Cloning-gnudatalanguage-gdl)) , and run `gdl/scripts/build_gdl.sh` several times:
 - `build_gdl.sh prep` will install the required libraries. (If you are not _sudoer_ you will get a list of libs. your admin. will installed for you.)
 - `build_gdl.sh configure` will run Cmake to prepare the Make file
 - `build_gdl.sh build` will build gdl in `build`.
 - `build_gdl.sh install`. This is the simplest way to be sure the paths and the links to the libs are OK.

A summary for Ubuntu/Debian (for RH/Fedora, just change apt-get by rpm ...): 
```
apt-get install git
apt-get install curl   // December 2021 because of Qhull ...
apt-get install cmake
apt-get install g++
mkdir GDL
cd GDL
git clone --recursive https://github.com/gnudatalanguage/gdl
cd gdl
./scripts/build_gdl.sh prep   <<-- need to be sudo to add set of official packages
./scripts/build_gdl.sh configure
./scripts/build_gdl.sh build
(./scripts/build_gdl.sh check)
./scripts/build_gdl.sh install  
```

then you should be able to start GDL by : `./install/bin/gdl`

This efficient and simple way was successfully tested on : Ubuntu 16.04 LTS, 18.04 LTS (may have a glitch due to Magicks libs), 20.04 LTS, 22.04 LTS; Debian 9, 10, Sid; Fedora 28

## use 'cmake'
- The default installs GDL at the end in a _root_ directory. For a custom or _user_ installation use the CMake flag `-DCMAKE_INSTALL_PREFIX=`, which can be a absolute or relative path.

```
git clone --recursive https://github.com/gnudatalanguage/gdl
cd gdl
mkdir build
cd build
cmake --fresh ..
make -j N    # N depending the number of cores you have; getconf _NPROCESSORS_ONLN
make test
make install
```
- The `--fresh` option is only important after each installation of a requested package that was not found by `cmake`, it is **mandatory** to clean the cache before running again cmake.

It is totally possible to compile only a subset of GDL, i.e. : 
```
cmake .. -DOPENMP=OFF  -DHDF=OFF -DCMAKE_INSTALL_PREFIX=../install
```

Finally, you can run GDL with
```
gdl
```
or for user installs
```
gdl/install/bin/gdl
```
